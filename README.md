# Presentation Resources & Skills — Tejveercode/presentation-Resources-And-Skills

This is the root resource and skills repository for a presentation-generation agent.
It holds no application code. The agent's runtime lives elsewhere; this repo defines
**what resources the agent can draw on to analyze software projects and produce
professional academic PowerPoint presentations.**

## What belongs here

- **Skills** — one folder per skill under its category directory, each with a `SKILL.md`
  describing what the skill does and when the agent should use it.
- **`SKILL_INDEX.md`** — the catalog of installed skills, grouped by category.
- No app source, no build config, no dependencies.

## Status

The repo structure is in place; skills are being populated in later passes. No external
skill repositories have been added yet, and skill folders not shown in the index are
intentional placeholders.
